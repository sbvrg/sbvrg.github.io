Features

A stack language for a shell

The prompt runs omega, a postfix language related to Forth. Commands and programs are written in the same language.

Every line is a transaction

When a word on a line fails, the whole line is undone. back undoes up to 64 lines that succeeded, and redo reverses a back.

Exact integers

Integers that overflow 64 bits become bignums, up to 2^65536. Compiled code does the same.

Infinity as a value

omega and aleph0 can be added, multiplied and compared like other numbers. See ordinals and cardinals.

A JIT with a disassembler

A quote is compiled to x86-64 machine code the second time it runs. xray disassembles the result. See JIT.

Four tabs

Four tabs run at the same time under a preemptive scheduler. Each tab has its own stack and its own definitions.

Ring 0

All code runs in ring 0. peek, poke, in, out, cpuid and pci read and write memory, I/O ports and PCI devices. See omega for smarties.

Saved after every line

An installed system writes its state to disk after every line that succeeds. The state is stored as omega source. See saving.

Its own bootloader

Installed disks boot with Subverge's own MBR and second stage loader. GRUB is used only on the ISO. See boot.

Windows

Up to four tabs on the screen at once, split like a tiling window manager. Super-Enter opens a window and Super-W closes it.

Emacs keys

The prompt, the pager and the editor use the keys of Emacs, with M-x, help keys and key bindings that you write in omega (keys).

phi

A tree of sets for named values, saved on the disk, with a directory editor (phi).

Requirements

  • QEMU. Subverge has only been tested in QEMU.
  • 256 MB of RAM for the virtual machine.
  • A disk image you don't care about, if you want to install it.
  • Some programming experience.
