Words

The everyday words, grouped as help groups them. 'word help documents any of them. All words has the complete table, and omega for smarties covers the memory, port, screen, machine and compiler words.

syntax

[ ] quotes, :name definitions, ->name and { a b } locals, 'name symbols (names), "text" strings, 42 0x2a numbers, # comments.

stack

dup drop swap over rot nip depth empty. See stack.

math and logic

+ - * / mod ^ neg abs min max, = < > <= >= and or not, and bitwise & | xor ~ << >>. See numbers. + * ^ also work on ordinals.

flow

do if when unless times for while each map filter eval trace try. See flow, and catching for try.

lists and text

list range append cat len at first last rest has spread on quotes, and str hex chr slice pad find split >num upper on strings.

io

. say write emit nl color key key? waitkey ask.

key waits for a key and returns its code, key? returns -1 immediately if no key is waiting, and waitkey waits up to a given number of ticks. The arrow keys are 256 to 259, in the order up, down, left, right.

names

get forget >sym defined? see words edit. See names.

world

help back stats save home root open unit src welcome. See help, back, saving, root, units and startup.

infinity

omega epsilon0 omega1 aleph0 aleph1 aleph continuum card ordinal?. See ordinals and cardinals.

time

ticks hz time idle sleep rand. The timer runs at 100 ticks a second, so 100 sleep waits one second. In QEMU the clock is UTC unless configured otherwise (QEMU).

tools, demos and games

The programs in root, described in tools, demos and games.

util

sq inc dec kb mb uptime >hex fmt attr fill bar header quit-key?. Small helpers used by the programs, available to yours as well. quit-key? is true for q, Esc and Ctrl-C, which is why those keys exit almost every program. The drawing helpers are described in screen.

helpers

Words used internally by the root programs, listed by 'helpers help. user, host and os are the strings shown on the sys screen (startup).
