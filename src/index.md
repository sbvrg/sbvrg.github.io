This is **Subverge**, a radical and experimental 64-bit operating system written from scratch.

[Features](features.md)

Download [subverge.iso](https://github.com/texivi/Subverge/releases/latest/download/subverge.iso) or the [source](https://github.com/texivi/Subverge), then follow the [installation](installation.md) page.

## Getting started

READ THE [README](readme.md) AND THE [EXPECTATIONS](expectations.md) FIRST. Then run `learn`, and only after that open an [issue](bugs.md).
