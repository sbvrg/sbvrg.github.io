FAQ

General

Is Subverge a Linux distribution?

No. The kernel, ordinal, was written for Subverge, and so were the bootloader, the shell, the editor and every program. Subverge is built on Linux, with gcc and nasm, but none of Linux ends up in the ISO apart from GRUB, which only boots the live system.

Is it a TempleOS fork?

No. Subverge took a few ideas from TempleOS, mainly a shell that is also the compiler and running everything in ring 0, but none of its code. The language, the kernel and the way lines are undone are different. See history.

Why is it called Subverge?

The name comes from subvert and diverge. See history.

Can I use it every day?

No. It runs in QEMU, has no network, no files and no protection between programs, and a bad poke can take the whole machine down. It is a system to explore and program in. Read the expectations.

Is there a roadmap?

Yes, see the roadmap.

Running it

Does it run on real hardware?

It is untested. Read hardware first, and report the result either way.

Does it run in VirtualBox, VMware or Hyper-V?

They are untested. A virtual machine with IDE disks, a PS/2 keyboard and BIOS booting should work, but only QEMU is tested.

Why can't it see my disk?

Subverge only has an IDE driver. Attach the disk image with -hda, or with -drive file=disk.img,format=raw,if=ide. disks lists what the kernel found (installation).

Where are my files?

Subverge has no files. Your definitions are kept in your tab's world, programs are kept in root, and an installed disk saves both.

Why was my work lost after a reboot?

The live ISO doesn't save anything. Install Subverge to a disk image to keep your work. An installed system saves after every line that succeeds, so the most you can lose is the line you were typing.

I booted the new ISO and sys still shows the old version

You booted with an installed disk attached. The live system loads the root and tabs saved on that disk, and the saved root still has the old sys. The kernel and the built-in words are new. See upgrading an installed disk. Boot without -hda to see the new root.

The system

Is it POSIX-compliant?

No, and it never will be. Subverge has no processes, files, file descriptors or system calls for POSIX to describe. Programs are omega words, and memory, I/O ports and PCI devices are reached with words such as peek, in and pci@. See omega for smarties.

Does it have its own bootloader?

Installed disks use Subverge's own bootloader. The ISO uses GRUB.

Why does everything run in ring 0?

Every word at the prompt can read and write the machine directly, the same way TempleOS works. Separating programs from the kernel would need user mode, system calls and paging per process, and Subverge leaves that layer out. Transactions undo most mistakes, and the ones they can't undo are writes to the hardware.

Is it self-hosting?

No. Subverge has no C compiler or assembler of its own, so the kernel is built on Linux. The programs in root are omega source and can be edited and rebuilt inside Subverge (root).

Is it multi-user?

No. The user name on the sys screen is a string, and 'user open changes it.

Can I change the colours?

Yes. themes lists the themes and 'haelide theme switches to one. n r g b rgb changes a single colour, and logos lists the logos sys can draw. See themes and logos.

Why is the screen so small?

Subverge uses 80 by 25 VGA text mode, with the top row taken by the tab bar. gfx starts a 640 by 480 graphics mode, which can draw dots and boxes but not text yet. Text in graphics mode is on the roadmap. See screen.

Does it have networking, sound or a GUI?

Not yet. All three are on the roadmap.

The language

Why is the shell a programming language?

So that a command and a program are the same thing. A line you type at the prompt can be put in a quote, given a name and saved, and it becomes a program. See omega.

Why is everything written backwards?

omega is a postfix language, so you write 2 3 + instead of 2 + 3. The arguments go on the stack first and the word that uses them comes last. It needs no brackets or precedence rules. See stack.

Why are locals dynamically scoped?

A word can read the locals of the word that called it, which is sometimes useful and sometimes causes surprising bugs. See names.

How big can a number get?

Up to 2^65536, which is about 19,700 digits. A result past that fails with an error (bignums). The infinite values, such as omega and aleph0, are a different kind of value: they compare above every integer, but they are positions and sizes rather than very large integers (ordinals).

What is omega, the value?

omega pushes ω, the first position after all the natural numbers. It is the reason the shell is called omega. Watch Vsauce's How To Count Past Infinity, then see ordinals.

Why does omega 1 - fail?

Ordinals only support +, * and ^. ω has no position directly before it, so ω−1 isn't an ordinal. See ordinals.

Why did my whole line do nothing?

One of its words failed, so the whole line was undone. See transactions and errors.

How do I undo a line?

Type back. See back.

How do I stop a program that won't stop?

Press Ctrl-C. It stops the code running in the current tab and undoes the line. If the tab doesn't respond, switch to another tab with F2 to F4. The tabs are scheduled separately, so the others keep working.
