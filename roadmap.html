Roadmap

Subverge 0.9.3

  • text draws in graphics mode
  • window draws a titled window frame

Subverge 0.9.2

  • beep, for the PC speaker
  • Graphics mode with gfx, gfx-off, dot and box, the first step toward windows

Subverge 0.9.1

  • The haelide theme
  • Logos for sys, with logo, logos and logo@
  • type and fail

Subverge 0.9.0

  • Themes: dusk, raw, paper, amber and phosphor, remembered on installed disks
  • rgb for changing single colours
  • Bright background colours
  • redo
  • Tab completion at the prompt
  • apropos
  • Text words: lower, trim, starts?, ends?, replace, join
  • List words: reverse, sort, sum, fold, index
  • sqrt and gcd, for bignums too
  • pick, tuck and 2dup
  • cal, month and date
  • tiles
  • Go to line and duplicate line in scrawl

Subverge 0.8.0

  • Bignums up to 2^65536
  • Compiled code switches to bignums on overflow
  • Bignums in comparisons, conditions, str, >num, min, max and saved worlds
  • 0b binary literals
  • More learn lessons

Planned

  • UEFI booting
  • Text in graphics mode
  • Drawing through a back buffer
  • Mouse support
  • A desktop with windows
  • USB keyboards
  • SATA disks over AHCI
  • Networking
  • Sound
  • Multiple CPU cores
  • Floating point numbers
  • Support for real hardware
